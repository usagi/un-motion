# 更新・バックアップ・復元（Windows）

この手順は現行ソースの設定保存方式に対応します。公開済み旧版からの全組合せの移行確認を示すものではありません。

## 更新前に残すもの

1. Supervisorに保存中・未保存・保存失敗の表示があれば、保存するか不要な入力を破棄します。保持された入力を強制終了で失わないようにしてください。
2. 更新対象のCapturerを停止し、Supervisorを終了します。単独起動や別プロファイルのCapturerも確認します。
3. 通常は `%APPDATA%\UN Motion\` を、設定フォルダー外へ丸ごとコピーします。`conf.toml`、`profiles`、`settings.toml`、`deleted_profiles`など、存在するものをまとめて残します。
4. 設定が参照する外部ファイルと、使用中の配布物一式も残します。EXEだけでなく同梱DLL・モデル等を含めます。

`UN_MOTION_CONFIG_DIR` を指定して起動している場合は、そのフォルダーが保存先です。起動方法と保存先の対応を記録してください。`%APPDATA%` はエクスプローラーのアドレス欄へ入力できます。

## 新しい版へ更新する

新しい配布物を別フォルダーへ全て展開し、`un-motion-supervisor.exe` を起動します。通常起動では既存の設定保存先を使うため、EXEを別の場所に置いても設定の隔離にはなりません。

編集対象、次回起動対象、入力カメラ・外部入力、送信先を確認してからCapturerを起動します。保存済みであることと、現在稼働中の個体へ反映されたことは別です。反映失敗や再起動待ちの表示があれば対象個体を確認します。複数個体を使う場合は、別プロファイルの入力・送信先を変えていないことも確かめてください。

## 次回起動用の選択を保存できない場合

プロファイルを選択すると、編集対象が切り替わり、その選択を次のSupervisor起動時にも使うために保存します。保存に失敗した場合も現在の編集対象は変わりませんが、再起動後の選択は以前のままです。

画面下部に表示される対象名を確認し、保存先の書込み制限や他のアプリによるファイルの使用が解消してから「次回起動用の選択を再保存」を押します。保存処理中は再保存ボタンを押せません。成功すると案内が消え、「アプリ再起動後の選択」が更新されます。詳しい原因は「診断情報」で確認できます。稼働中のCapturerを切り替える操作ではありません。

## 指定したプロファイルを起動できない場合

Capturerの起動時に `requested --active-profile ... was not found` と表示された場合、指定したプロファイルを読み込めていません。別のプロファイルを代わりに動かすことはせず、入力・送信の開始前に停止します。Supervisorで対象が存在することと保存先を確認し、削除していた場合は必要に応じて復元してから起動してください。

## 元の版へ戻す

1. 戻す保存先を使うSupervisorとCapturerを全て終了します。
2. 更新後の設定を、更新前のバックアップとは別に残します。
3. 設定フォルダーを更新前のコピーへ戻します。新旧ファイルを混ぜず、外部参照ファイルも対応する版へ戻します。
4. 元の配布物を元と同じ保存先指定で起動し、プロファイル・入力・送信先を確認します。

新しい版で保存した設定を古いEXEへ渡すだけでは復元になりません。画面内の削除済みプロファイルの復元は、アプリ全体を旧版へ戻す操作とは別です。

### 旧形式の平滑化設定

旧プロファイルの `smoothingPreset` も、現在のEMA・One Euro欄に実際の有効状態と強さを表示します。画面を開くだけでは保存内容を変更しません。平滑化を編集するときに、旧プリセットの効き方を引き継いだ明示設定へ一括保存します。両方式をOFFにした後、旧プリセットだけが残って平滑化を続ける状態を防ぎます。
